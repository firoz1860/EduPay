## Part B — How the product itself uses AI (design guarantee)

EduPay's AI assistant is deliberately constrained:
- **It never makes financial decisions and never modifies any record.** It has no
  database write path.
- **It only explains verified figures.** The backend first computes deterministic
  aggregates (`backend/src/modules/ai/ai.context.ts`) and passes *only* those to the
  provider. The system prompt forbids inventing numbers and instructs it to say
  information is unavailable when the data is absent.
- **Provider abstraction:** `AIProvider` with a `MockProvider` (deterministic, no key
  required) and an OpenAI-compatible provider selected by `AI_PROVIDER`. The app runs
  fully without an AI key.
- **Determinism:** the OpenAI path uses temperature 0; the mock path renders answers
  directly from the verified figures.

This division keeps every financial calculation and reconciliation decision
backend-controlled and auditable, with AI limited to human-readable explanation.
